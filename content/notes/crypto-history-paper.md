摘要：密码学是保障信息安全的核心技术，其发展经历了从古典艺术到现代科学、从对称体制到公钥体制再到抗量子时代的持续演进。本文首先将密码学发展划分为古典密码学、现代对称密码学与现代公钥密码学三个阶段，剖析各阶段的代表性成果、技术特征与内在演进动力；继而从密码体制基本模型出发，系统论述DES、AES等对称密码算法和RSA、ECC等公钥密码算法的数学原理与设计思想，并阐述哈希函数与数字签名在完整性和真实性保障中的原理与作用；在此基础上总结密码学在网络安全、电子商务、区块链、云计算与物联网等领域的应用现状，重点分析量子计算对传统公钥密码体制的威胁及后量子密码、量子密钥分发等应对路径；最后展望后量子密码标准化、同态加密实用化、区块链密码学演进等未来方向。研究表明，密码学始终在安全需求、攻击威胁与理论创新三者互动中螺旋上升，构建可平滑迁移、抗量子且兼顾性能与隐私的密码体系，是未来研究的核心命题。

关键词：密码学；对称密码；公钥密码；量子计算；后量子密码

### 一、引言

随着数字经济的深度发展与网络空间与现实世界的全面融合，信息安全已经成为国家安全、社会稳定与经济运行的重要基石。密码学作为保障数据保密性、完整性、真实性与不可否认性的核心技术，其战略地位不可替代：无论是网络通信、电子支付，还是政务系统、工业控制与云计算平台，安全边界的建立都以密码机制为底层支撑。密码算法与协议的质量直接决定信息系统的安全水平，密码管理上的任何疏漏都可能使整个防护体系形同虚设[1]。因此，深入理解密码学的基本原理，把握其发展脉络，是从事信息安全研究与实践的基本功。

从历史视角看，密码学并非一蹴而就的现代学科，而是在数千年实践积累的基础上，于20世纪中叶完成从“技艺”到“科学”的跃迁，并在此后不断因应用需求与攻击威胁的双重驱动而演化[1]。系统考察这一历程，不仅能够揭示加密体制、密码分析与通信理论之间相互促进的内在逻辑，也能够为评价当前各类安全方案、研判未来技术路线提供认识框架。

当前，密码学正处在一个承前启后的关键节点。量子计算研究的快速推进表明，以大整数分解和离散对数为困难假设的传统公钥密码体制将面临根本性威胁[2]；与此同时，美国国家标准与技术研究院（NIST）主导的后量子密码标准化工作已经取得阶段性成果并开始向工程落地推进[3]。云计算、区块链、物联网等新场景还对密码算法的轻量性、可证明安全性与隐私保护能力提出了更高要求。在这种背景下，系统梳理密码学原理、总结应用实践并审视前沿挑战，既有突出的学术价值，也有紧迫的现实意义。

本文以“发展历程—原理算法—应用挑战”为主线展开研究：首先按古典密码学、现代对称密码学与现代公钥密码学三个阶段梳理密码学演进脉络；继而深入剖析对称密码、公钥密码、哈希函数与数字签名背后的数学原理和设计思想；最后系统归纳密码学的典型应用领域，重点分析量子计算带来的安全挑战，并对后量子密码、量子密码、同态加密与区块链密码学等未来方向进行展望。

### 二、密码学发展历程

#### （一）古典密码学阶段（1949年之前）

古典密码学的历史几乎与人类文明史同样悠久。考古与文献研究表明，古埃及人早在约公元前1900年的铭文中就使用非标准的象形符号传递特殊信息；斯巴达人约在公元前5世纪使用“天书”（Scytale）木棍对消息进行置换；古罗马的凯撒则使用固定的移位代换进行军事通信。在中国，古代军事与政治实践中同样孕育了丰富的保密通信思想：姜太公的《阴符》《阴书》通过约定符号与拆分传递实现保密，《武经总要》等兵书所载的“字验”方法借助预先约定的字词传递军情，历代文人使用的藏头、反切等技巧也带有原始编码与隐写的性质。这些史实表明，保密通信是人类社会冲突与协作的必然产物。

从技术形态看，古典密码主要分为代换密码与置换密码两大类。代换密码按照一定的规则用其他字符替代明文字符，如凯撒密码属于单表代换，维吉尼亚密码属于多表代换；置换密码不改变字符本身，而按某种规则重新排列字符的位置，如斯巴达天书。在此基础上，公元9世纪阿拉伯学者金迪对频率分析方法的阐述，标志着系统的密码分析思想开始萌芽：只要密文足够长，单表代换即可借助字母出现频率的统计规律被攻破。加密与解密、设计与分析的初步对立由此形成，密码对抗的基本形态在古典阶段已经确立。

总体而言，这一阶段的密码学表现出鲜明的“艺术”特征：密码的设计与分析主要依赖个人的经验、直觉与技巧，缺乏统一的数学理论框架；算法本身往往被当作秘密保存，一旦泄露便全盘失效，尚未形成“算法公开、密钥保密”的现代观念。然而，正是这些朴素而丰富的实践，提出了保密强度如何度量、密钥如何安全管理、密文如何被系统分析等根本性问题，为现代密码学的诞生准备了问题素材和历史铺垫。

#### （二）现代密码学的对称密码阶段（1949—1975年）

1949年，香农（C. E. Shannon）发表《保密系统的通信理论》，首次将信息论引入密码学，被视为现代密码学诞生的标志性事件。香农用熵刻画信息的不确定性，严格定义了“完善保密”概念，证明一次一密是唯一能够达到完善保密的密码体制；他还提炼出混淆与扩散两大设计原则，为分组密码与序列密码的设计奠定了理论基础。自此，密码系统的安全性不再是无法言说的经验判断，而成为可以在信息论框架下度量和分析的科学对象，密码学由此完成了从艺术到科学的转变。

在这一阶段，以对称密码为主体的理论与工程同步发展。两次世界大战期间，转轮密码机等机械化设备投入使用，盟军对德国恩尼格玛密码机的破译更催生了早期的计算性密码分析；战后，流密码与分组密码的理论研究逐渐成熟。20世纪60年代末至70年代初，IBM公司的费斯妥（H. Feistel）团队研制出Lucifer算法，系统提出以轮函数迭代为核心的Feistel结构，成为现代分组密码设计的里程碑。1973—1974年，美国国家标准局（NBS，今NIST）面向社会公开征集数据加密标准，DES算法应运而生并于1977年正式成为联邦信息处理标准[4]。

DES的意义不仅在于提供了一种可大规模部署的分组密码，更在于确立了“算法公开、仅密钥保密”的现代密码标准化范式[1]。它的公开征集与评审推动了密码学学术共同体的形成，也使密码分析从战时的机密活动转变为开放的学术研究。从演进动力看，这一阶段密码学由战争与外交通信的保密需求，转向社会信息化进程中普遍化的通信安全需求；由密码机的机械化实现，转向集成电路之上的标准化算法。密码学的学科化、公开化与工程化由此起步，为下一阶段的理论突破积蓄了力量。

#### （三）现代密码学的公钥密码阶段（1976年至今）

对称密码虽然加密效率高，却存在两个难以逾越的瓶颈：一是密钥分发问题，n个用户两两保密通信需要共享约n(n-1)/2个密钥，在开放网络中如何安全地传递这些密钥本身就是一个难题；二是对称体制难以自然地提供数字签名等认证服务。1976年，迪菲（W. Diffie）与赫尔曼（M. Hellman）发表《密码学的新方向》，首次公开提出公钥密码的思想：加密与解密使用不同的密钥，公钥可以自由发布，私钥由持有者秘密保存[5]。公钥思想借助单向陷门函数同时回应了密钥分发与数字签名两大需求，被视为密码学史上影响最为深远的变革之一。

1978年，里维斯特（R. Rivest）、沙米尔（A. Shamir）与阿德曼（L. Adleman）提出RSA算法，给出了公钥思想的第一个完整实现。RSA的安全性建立在大整数分解困难性之上：加密密钥完全公开，而由公开模数恢复私钥在计算上等价于分解两个大素数的乘积[6]。RSA不仅实现了无需预先共享密钥的保密通信，还开创了基于公钥密码的数字签名，深刻影响了此后数十年的网络安全架构与电子商务形态。1985年，米勒（V. Miller）与科布利茨（N. Koblitz）分别提出椭圆曲线密码（ECC），其安全性基于椭圆曲线点群上离散对数问题的难解性，能够以更短的密钥提供相当的安全强度[5]，尤其适合计算与带宽受限的应用场景。

公钥密码阶段最深刻的变化，在于安全模型从“对算法的信任”转向“对数学困难问题的依赖”：方案的安全性逐步与算法实现细节解耦，而与所依据的大整数分解、离散对数等数学困难问题深度绑定[5]。此后，可证明安全理论逐步完善，随机谕言机模型与标准模型成为方案安全论证的基本框架[7]，公钥密码研究由此进入以困难问题假设与严格安全证明为特征的新阶段。进入21世纪，量子计算研究取得长足进步，传统公钥密码赖以生存的困难问题面临颠覆性挑战，NIST后量子密码标准化进程随之启动并持续推进[3]。从RSA、ECC到格基等后量子方案，公钥密码正在经历又一次体系性的升级与重构[8]。

### 三、密码学原理与算法

#### （一）密码学的基本原理

密码体制通常可以形式化为五元组：明文、密文、密钥、加密算法与解密算法。发送方使用密钥K对明文M加密，得到密文C=EK(M)；接收方使用相应密钥解密，恢复明文M=DK(C)。若加解密使用相同密钥，或者由一方密钥能够容易地推导出另一方密钥，则为对称密码体制；反之则为非对称（公钥）密码体制。任何实用的密码体制都必须满足两个基本条件：在正确密钥下能够正确解密；在未知密钥的情况下，即使攻击者掌握算法细节和大量明密文对，也难以恢复明文或密钥。

古典密码学把算法本身当作秘密，而现代密码学普遍接受柯克霍夫原则：密码体制的安全性不应依赖算法的保密，而应仅依赖密钥的保密[1]。这一原则促使密码算法公开接受同行评议，使“公开设计、公开攻击”成为发现与修补漏洞的基本机制。在此基础上，现代密码学进一步引入计算复杂性理论与可证明安全方法，要求攻击者无法在多项式时间内以不可忽略的概率破坏方案，随机谕言机模型与标准模型则是两种典型的安全论证框架[7]。

数学是密码学的根基。模运算、素数理论、欧拉定理与离散对数构成了RSA等公钥方案的理论基础[6]；群、环、域以及有限域GF(2n)上的运算，是ECC等公钥算法设计的基本工具[5]；而计算复杂性理论中的困难问题假设则是密码安全性最终所系。可以说，一部现代密码学发展史，同时也是数学工具持续进入信息安全领域、将直觉性安全转变为可验证安全的历史。

#### （二）对称密码算法

DES是首个被广泛部署的现代分组密码标准。它以64比特为分组，以56比特为有效密钥（另有8比特奇偶校验位），采用Feistel网络结构进行16轮迭代：每一轮中，右半部分经扩展置换、与轮密钥异或、S盒代换和P置换后与左半部分结合，随后左右交换进入下一轮[4]。Feistel结构的突出优点是加解密过程结构相近，便于硬件实现。然而，DES的56比特密钥空间过小，随着计算能力的持续提升已难以抵御穷举搜索；同时，其S盒设计准则在早期未公开，曾引起学界对其安全性的质疑[9]。为延长其使用周期，3DES通过三次DES加密将标称密钥长度扩展至112比特或168比特，但实际有效安全强度低于该数值，且处理速度较慢。

针对DES的不足，NIST于1997年公开征集高级加密标准，并于2001年正式采纳比利时密码学家达门（J. Daemen）与里门（V. Rijmen）设计的Rijndael算法，发布为FIPS 197标准，即AES。AES分组长度为128比特，支持128、192与256比特三种密钥长度，采用替换-置换网络（SPN）结构，轮数分别为10、12与14轮。每一轮依次执行字节代换、行移位、列混合与轮密钥加：字节代换基于有限域GF(28)上的乘法逆元与仿射变换构造S盒，列混合利用GF(28)上的多项式乘法实现扩散，整体结构数学上清晰可证。AES能够有效抵抗差分密码分析与线性密码分析，在软件和硬件平台上均具有出色的实现效率，密钥长度亦可按安全等级灵活选择[9]。

对比DES与AES可以清晰地看到两代对称算法的差异。在安全性上，AES的密钥空间、分组规模与抗密码分析能力全面优于DES，DES作为上一代标准已逐渐退出主流应用；在效率上，AES在现代处理器上的吞吐率显著高于DES，且密钥长度可扩展，能够适应从嵌入式设备到高性能服务器的不同需求；在适用场景上，AES已成为当前部署最广泛的现代对称加密标准，DES则主要作为历史遗留系统兼容与教学示例存在[9]。实际部署时，还需要将AES与恰当的工作模式配合使用，例如CBC、CTR或带认证的GCM模式，以同时保障语义安全与完整性认证。

#### （三）公钥密码算法

RSA的安全性建立在如下困难问题上：给定两个大素数p与q的乘积n=pq，在不知道p、q的情况下，于经典计算模型中恢复n的分解是困难的。其密钥生成过程为：选取两个足够大的素数p、q，计算模数n=pq与欧拉函数φ(n)=(p-1)(q-1)；选取与φ(n)互素的加密指数e，再用扩展欧几里得算法计算满足ed≡1(mod φ(n))的解密指数d。加密时计算C=Me mod n，解密时计算M=Cd mod n，其正确性由欧拉定理保证。因此，任何能够分解n的攻击者都可以计算φ(n)并恢复私钥d；反之，在缺少有效分解算法的情况下，RSA的安全性得以维持[6]。

需要指出的是，RSA的“困难性”建立在当前经典算法无法高效分解大整数这一经验事实上，而非严格的数学证明。随着数域筛法等算法的改进与分布式计算的普及，可分解整数规模不断刷新纪录，这提醒人们密钥长度必须随计算能力增长而持续升级[6]。同时，RSA的朴素实现还存在小加密指数、共模攻击、填充攻击等风险，实际使用必须采用OAEP等安全填充方案，并在协议层加以规范。

ECC基于有限域上椭圆曲线点群中离散对数问题的难解性。设p为大素数，椭圆曲线y²=x³+ax+b(mod p)上的点连同无穷远点构成一个阿贝尔群，点加与标量乘kP=P+P+…+P构成其基本运算；给定基点P与整数k，容易计算kP，但由P与kP恢复k在经典计算模型下是困难的[5]。ECC最突出的优势是密钥短、效率高：在达到相当安全强度的前提下，ECC所需密钥长度明显短于RSA，因此其在带宽、存储与计算资源受限的移动设备、物联网终端与智能卡等场景中优势明显[5]。以SM2为代表的国产椭圆曲线公钥密码算法，已经广泛应用于电子认证服务与商用密码基础设施。

RSA与ECC同属公钥密码，但在数学基础与性能特征上各有取舍：RSA理论成熟、生态完善、实现资料丰富，ECC则以更短的密钥提供相当安全强度，计算与传输开销更低。现代密码工程普遍采用混合加密策略：先用公钥算法完成身份认证与会话密钥协商，再用对称算法加密大批量业务数据，从而兼顾安全性与效率。这种“公钥协商密钥+对称加密数据”的分工模式，构成了SSL/TLS等主流安全协议的基本骨架[10]。

#### （四）哈希函数与数字签名

哈希函数将任意长度的消息压缩为固定长度的摘要，在完整性验证中扮演“数字指纹”的角色。一个安全的密码哈希函数应当满足抗原像性、抗第二原像性与抗碰撞性：给定摘要难以反推原文，给定一条消息难以构造另一条与之摘要相同的消息，更无法找到任意两条发生碰撞的消息。MD5与SHA-1等早期算法已被证明存在实际的碰撞攻击，SHA-2（SHA-256、SHA-512）与新一代SHA-3已成为当前主流；而在物联网等资源受限环境中，低功耗、小面积的轻量级哈希函数设计与实现是持续的研究热点[11]。

哈希函数本身不包含密钥，因此通常与密钥结合构造消息认证码（如HMAC），以同时提供完整性与真实性。数字签名通常先对消息摘要签名，再与原文一并发送，这样既能提高效率，又符合安全模型的要求。数字签名通过私钥签名、公钥验签，实现身份认证、消息完整性与不可否认性三大安全目标[12]，其经典实现包括RSA签名、基于离散对数的ElGamal类签名以及基于椭圆曲线的ECDSA、SM2签名等。随着隐私保护需求的增长，可修订数字签名等具有特殊性质的签名方案允许在不破坏签名有效性的前提下删改消息的局部内容，为证书、档案与法律文书等场景提供了兼顾真实性与隐私的解决方案[13]。

### 四、密码学应用与挑战

#### （一）密码学的应用领域

在网络与通信安全领域，SSL/TLS协议是互联网保密通信的基础设施：它通过证书体系完成服务器身份认证，通过密钥交换协议协商会话密钥，再以对称加密与认证加密算法保护传输数据的机密性与完整性，HTTPS、安全电子邮件等应用均构建于此类机制之上[10]。然而，协议设计缺陷与实现漏洞仍不断被披露，例如握手协议降级、证书校验缺失与侧信道泄露等，说明“正确使用密码”与“设计安全协议”同样重要[10]。

在电子商务与电子政务领域，在线交易要求数据在传输与存储全过程中的机密性、完整性、真实性与不可否认性，公开密钥基础设施（PKI）、数字证书与数字签名由此成为核心支撑。数字签名使电子合同、电子票据与电子证照获得与传统签章相当的法律效力，相关技术也由早期的RSA、DSA逐步向更高效的椭圆曲线签名演进[12]。

在区块链领域，哈希链、默克尔树、数字签名与共识机制等密码原语被组合成去中心化的信任基础设施：哈希运算保证区块数据难以篡改，数字签名保证交易授权与不可抵赖，共识机制使互不信任的节点在无第三方背书的环境中就账本状态达成一致[14]。与此同时，区块链在密钥托管、智能合约安全与链上隐私等方面仍面临突出风险，分布式密钥管理、门限签名与可审计匿名等密码技术成为研究重点[15]。

在云计算与大数据领域，数据外包带来的隐私保护问题催生了同态加密等前沿密码技术。同态加密允许直接在密文上执行运算并获得加密的计算结果，理论上能够实现“数据可用不可见”，是云计算环境下安全外包计算的关键路径；全同态加密方案虽已从理论走向工程原型，但噪声管理、计算开销与具体应用协议设计仍然是制约其规模化部署的主要瓶颈[16]。

在物联网领域，海量终端普遍存在计算能力弱、存储空间小、电池寿命有限等特点，要求密码算法在保证安全的同时做到轻量高效，轻量级分组密码、轻量级哈希函数以及面向受限环境的认证与密钥协商协议因此受到学术界与产业界的广泛关注[11]。

#### （二）密码学面临的挑战

当前密码学面临的最大变量是量子计算。Shor算法能够在多项式时间内求解大整数分解问题与离散对数问题，从而直接威胁RSA、ECC、DSA等基于这两类困难问题的公钥密码体制；Grover算法虽然只对对称密码提供平方加速，但也意味着AES-128等算法的有效安全强度大致降至64比特量级，密钥长度需要相应加倍[2]。尽管大规模容错量子计算机尚未问世，“先窃取、后解密”的攻击策略已经使高价值敏感数据的抗量子迁移具有现实紧迫性。

应对量子威胁的主要技术路径是后量子密码（PQC）。NIST自2016年启动后量子密码标准化征集，并于2024年正式发布首批标准：基于格的ML-KEM（Kyber）与ML-DSA（Dilithium），以及基于哈希的SLH-DSA（SPHINCS+）[3,17]。基于格的方案因安全性与性能相对均衡而备受关注，其安全性可归约到带错误学习等格上困难问题[3]；但后量子方案的密钥与签名尺寸普遍大于RSA与ECC，安全强度的精确评估、侧信道防护以及向既有应用规范的平滑迁移，仍是亟待解决的工程问题[8]。

对称密码面临的量子威胁相对温和，但也需要前瞻布局：一方面可以通过加倍密钥长度来抵消Grover搜索的平方加速；另一方面，量子密钥分发（QKD）利用量子不可克隆定理与测量坍缩特性，能够实现具有信息论安全性的密钥协商，理论上不惧任何计算能力的攻击者。近年来，基于光子集成技术的QKD系统与量子随机数生成器在传输速率与设备小型化方面取得显著进展，正在推动量子保密通信从实验室走向实用化网络[18]。

#### （三）密码学的未来趋势

展望未来，密码学将呈现多条主线并行的演进态势。其一，后量子密码的工程化与规模化部署将成为未来一段时期的重点：在算法与标准日趋成熟的同时，仍需着力解决后量子算法密钥与签名尺寸较大、与既有应用规范兼容困难等障碍，实现从传统公钥密码到后量子密码的平滑迁移[8]。其二，量子密码将从点对点实验走向组网应用：在量子密钥分发基础上发展量子中继与量子安全网络，并与经典密码体系协同构成纵深防御[18]。其三，以同态加密为代表的隐私计算技术将加速实用化，为数据要素的合规流通与个人隐私保护提供基础性工具[16]。其四，区块链密码学将向可监管、可扩展与抗量子方向演进，分布式密钥管理、门限签名、可审计匿名与轻量级共识密码等方向将持续活跃[15]。此外，人工智能与密码学的双向赋能同样值得期待：人工智能可用于自动化密码分析与安全验证，而密码学也将为人工智能模型的训练、推理与权属保护提供支撑，二者融合有望开辟新的研究空间。

### 五、结语

从古埃及铭文与凯撒移位代换，到香农以信息论为密码学奠基，再到迪菲、赫尔曼与RSA开启的公钥革命，直至今天面向量子时代的密码标准重构，密码学始终循着“应用需求提出命题、攻击威胁暴露短板、数学理论提供工具、标准工程推动落地”的路径螺旋演进。这一历程表明，密码学不仅是算法的集合，更是一套以困难问题假设为基石、以可证明安全为方法论、以标准化与工程化落地为归宿的完整知识体系。在数字时代，密码学已经成为网络空间信任的基石，其战略地位只会更加突出。未来研究的重点方向包括：构建能够平滑迁移的抗量子密码体系，推动同态加密与隐私计算的规模化应用，完善量子密钥分发与经典密码融合的网络架构，并持续关注新型攻击范式对既有密码体制的冲击。唯有坚持基础理论、工程实现与安全生态的协同创新，才能在不确定的威胁环境中有效守护数字世界的安全。

## 可复现的基础实验

这篇是概念文章，但其中每个阶段都可以用本地命令验证。

### 1. 对称密码

对应实验：

- [DES 加密算法实验](/notes/crypto-des-cipher/)

```bash
openssl enc -des-ecb -K 0123456789abcdef \
  -nosalt -nopad \
  -in <(printf '12345678') \
  -out /tmp/des.bin

xxd -p /tmp/des.bin
```

### 2. 哈希

对应实验：

- [MD5 算法实验](/notes/crypto-md5/)

```bash
printf 'abc' | md5sum
printf 'abc' | sha256sum
```

### 3. 公钥密码

对应实验：

- [RSA 加解密实验](/notes/crypto-rsa-lab/)

```bash
openssl genpkey -algorithm RSA \
  -pkeyopt rsa_keygen_bits:2048 \
  -out /tmp/rsa-private.pem

openssl pkey -in /tmp/rsa-private.pem \
  -pubout -out /tmp/rsa-public.pem

openssl pkeyutl -encrypt \
  -pubin -inkey /tmp/rsa-public.pem \
  -in <(printf 'history-demo') \
  -out /tmp/rsa-cipher.bin

openssl pkeyutl -decrypt \
  -inkey /tmp/rsa-private.pem \
  -in /tmp/rsa-cipher.bin
```

### 4. 签名

```bash
openssl dgst -sha256 -sign /tmp/rsa-private.pem \
  -out /tmp/message.sig <(printf 'important message')

openssl dgst -sha256 -verify /tmp/rsa-public.pem \
  -signature /tmp/message.sig <(printf 'important message')
```

预期：

```text
Verified OK
```

### 5. 安全迁移结论

这些命令只验证算法行为，不代表生产安全：

- RSA 加密需要 OAEP，不是直接 `pkeyutl` 裸加密；
- MD5 不能用于签名/口令；
- DES 已不安全；
- 后量子迁移需要评估密钥、证书、协议与库存。
