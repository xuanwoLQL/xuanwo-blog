发布前必修的硬伤（P0）

P0首页统计数字全为 0 —— 发布的是旧构建

线上首页显示"0篇技术笔记、0篇 CTF Writeup、0个公开项目"，横幅却显示"59 篇笔记 · 17 个公开项目"，数据自相矛盾。已定位根因：统计数字由 initCounters() 动画渲染，但线上加载的 main.min.ada32aaf….js（13960 字节）不含该函数——本地 assets/js/main.js（31373 字节）已更新，public/ 却未重新构建，部署仍是旧版。

P0没有 HTTPS（443）—— nginx 里其实已写好路径

你的 nginx/blog 末尾注释里已经有完整步骤。建议在此基础上补 OCSP Stapling、HTTP/2、现代 TLS 参数；HSTS 等 HTTPS 稳定运行两周后再开。

修复

P0域名 + ICP 备案 —— 大陆服务器合规红线

当前 IP 直连 + server_name _ 带来两个问题：大陆境内服务器绑定域名必须 ICP 备案，否则会被阻断；且 HTTPS 证书只认域名，裸 IP + 无 HTTPS 投简历直接扣印象分。备案周期约 2–3 周，越早提交越好。

修复 
买域名 → 阿里云 ICP 备案 → 改 hugo.yaml 的 baseURL 为 https://你的域名/ → 重建部署
（canonical / og:url / sitemap 会随 baseURL 全部变对）

06 / SECURITY

安全维度补充（你既然是安全方向，这里会被重点问）

01CSP 的 unsafe-inline

script-src 保留 unsafe-inline 是因为 extend_head.html 里有内联脚本。面试官可能问"为什么不能去掉"——要能答出迁移方案（外链文件或 hash/nonce）。

02部署账号

build-upload.ps1 默认 root 用户 + SSH 22 直连。建议：低权限用户 + SSH Key 登录 + 禁止 root 登录 + 高位 SSH 端口。

03监控与回滚

已有 limit_req，可加 fail2ban 防爆破并在简历写"访问日志分析与异常 IP 封禁"；部署脚本是 tar 覆盖式，建议保留上一版本 tar 实现 5 秒回滚。

04HTTPS 后的配置清单

  • ssl_stapling on / verify on（OCSP 装订）
  • ssl_session_cache shared:SSL:10m
  • TLSv1.2/1.3，listen 443 ssl http2
  • HSTS：max-age=31536000; includeSubDomains（稳定后再加）
07 / INTERVIEW

面试官大概率会问的问题

提问建议应答要点
为什么选 Hugo 而不是 Hexo / VuePress？SSG 静态站安全性（无动态执行面）、构建速度、模板可定制性；实际覆盖了自定义首页模板 + 资源管线指纹
你的 nginx 为什么这么配？逐条讲：CSP/XFO 防注入与点击劫持、限流防扫描、分级缓存、隐藏文件拦截——这是最能展示深度的部分
HTTPS 怎么上？证书怎么续？certbot 自动续期（certbot renew + cron）、OCSP Stapling、HSTS 开启时机
SSG 和 SSR 的区别？为什么用 SSG？构建期 vs 请求期渲染；静态站无服务端代码 = 攻击面小，适合安全博客
你的博客有什么攻击面？诚实回答：纯静态 + nginx，几乎无动态攻击面；风险集中在 SSH 安全、证书、nginx 配置本身
为什么不用 GitHub Pages 免费托管？自建理由：可控性（自定义 nginx 行为、限流、日志）、国内访问速度、附属能力
59 篇笔记怎么保证质量？check_links.py、MD5 22 组向量对拍、Obsidian 导入流程
